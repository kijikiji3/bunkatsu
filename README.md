# bunkatsu
記録したいことをカテゴリごとに分割できる日記。起動時は表示中の各カテゴリについて、最新3件の記録だけを読み込みます。4件以上あるカテゴリは「残りn個を表示」から、全記録をスクロール可能なダイアログで確認できます。

左上のメニューからカード位置の初期化、Googleへのサインイン／サインアウト、CSVダウンロードを行えます。CSVには表示中とゴミ箱内のカテゴリの記録を、状態・カテゴリ名・進捗の分数・日時・本文の順で出力します。カテゴリはヘッダーの＋から増やせます。カードをヘッダーのゴミ箱へドラッグするとゴミ箱へ移動し、ゴミ箱から復元または完全削除できます。完全削除では、そのカテゴリ内の記録も削除されます。中央の青い＋をカードへドラッグすると進捗表示を追加し、分数を入力して進捗を変更できます。青い−を進捗表示付きカードへドラッグすると進捗表示を削除します。カード左上のドラッグハンドルをタップすると、カテゴリ名と送信ボタンの色を6色から切り替えられます。
